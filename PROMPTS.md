# AI Prompts Used

This project was built with Claude (Anthropic) as a pair-programming
assistant. Below is a summary of the prompts/instructions used to produce
it, in the order they were given.

1. **Initial brief** — pasted the full assignment (build a full-stack
   calculator: React + TypeScript frontend, Go backend REST API, basic and
   optional advanced operations, input validation, unit tests, README,
   optional Dockerfile), and asked what tooling would be needed to complete
   it (e.g. whether VS Code was required).

2. **Scope clarification** — confirmed two decisions before implementation:
   - Include all optional operations (exponentiation, square root, percentage),
     not just the four basics.
   - Include the optional Dockerfile / `docker-compose` setup for running the
     full stack together.

3. **"Continue"** — asked Claude to proceed with implementation after the
   scope was confirmed: build the Go backend, the React/TypeScript frontend,
   write unit tests for both layers with coverage, add Docker support, and
   write the README with setup instructions, API examples, and design
   rationale.

Within those instructions, Claude made and documented its own implementation
decisions (e.g. the exact shape of the `percent` operation, the calculator's
state-machine design, keeping the Go backend dependency-free, and the visual
design direction) — these are explained in the **Design decisions &
assumptions** section of `README.md` rather than repeated here.

All code was generated by Claude, then compiled, run, and tested
(`go build`, `go test`, `npm run build`, `npm test`) to confirm it actually
works before being included in this submission. Manual review and cleanup
were also done on the generated code (for example, tightening the
`useCalculator` hook's implementation and fixing two failing tests
discovered during the test run — a floating-point edge case in
`formatNumber` and a test double that didn't match the real `ApiError`
class).
